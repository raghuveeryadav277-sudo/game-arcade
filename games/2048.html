🔢 2048

Slide, merge, reach 2048!

Score: 0 Best: 0

How to Play

Use the arrow keys or swipe to slide all the tiles. When two tiles with the same number touch, they merge into one — and you score the new value. Reach the 2048 tile to win! If the board fills up with no moves left, the game is over.
